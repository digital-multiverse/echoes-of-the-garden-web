# 🌱 Echoes of the Garden — Website

Official presentation website for **Echoes of the Garden**, an idle creature collector coming to Steam.

> *A garden outside of time. Creatures born, grown, aged and permanently gone — leaving unique items that can never be replicated.*

**Live site:** [echoesofthegarden.com](https://echoesofthegarden.com)

---

## About the Game

Echoes of the Garden is a free-to-play idle creature collector where every creature has a real life cycle — born, grown, aged, and permanently dead. What they leave behind is unique and unrepeatable, tradeable on the Steam Community Market.

- 4 ecosystems, 28 creatures at launch
- Permanent death with inheritance system
- Steam Community Market integration (player-driven economy)
- No pay-to-win — all items generated by gameplay

**Status:** In development · Early Access target: ~month 13

## Local Development

No build step required. Open `index.html` directly in a browser:

```bash
git clone https://github.com/YOUR_USERNAME/echoes-web.git
cd echoes-web
open index.html        # macOS
# or
start index.html       # Windows
# or
xdg-open index.html    # Linux
```

The newsletter form runs in **preview mode** automatically when opened locally — it shows a success message without hitting any backend.

## Deployment (Netlify)

### First deploy

1. Push this repo to GitHub
2. Go to [netlify.com](https://netlify.com) → **Add new site** → **Import from Git**
3. Select this repo — build settings are auto-detected from `netlify.toml`
4. Deploy

### Newsletter setup

1. Create a free account at [resend.com](https://resend.com)
2. Create an **Audience** and copy the Audience ID
3. Get your API key from the Resend dashboard
4. In Netlify: **Site settings → Environment variables**, add:

```
RESEND_API_KEY       = re_xxxxxxxxxxxxxxxxxxxx
RESEND_AUDIENCE_ID   = xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

5. Redeploy — the newsletter is now live

### Custom domain

In Netlify: **Domain settings → Add custom domain** → follow the DNS instructions for Namecheap.
