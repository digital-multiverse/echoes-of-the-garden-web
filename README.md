# 🌱 Echoes of the Garden — Website

Official presentation website for **Echoes of the Garden**, an idle creature collector coming to Steam.

> *A garden outside of time. Creatures born, grown, aged and permanently gone. Every relic carries the name you gave it and the life it lived. No two share a story.*

**Live site:** [echoesofthegarden.com](https://echoesofthegarden.com/)

---

## About the Game

Echoes of the Garden is a free-to-play idle creature collector where every creature has a real life cycle — born, grown, aged, and permanently dead. Every relic carries the name you gave it and the life it lived.

- 4 ecosystems, 28 creatures (Roots + Ash at Early Access launch; Garden + Cave as content updates)
- Permanent death with inheritance system
- Steam Community Market — first major update after Early Access (ADR-012); Early Access ships without it
- No pay-to-win and no real-money shop — all items generated by gameplay

**Status:** In development · playable on [itch.io](https://echoes-of-the-garden.itch.io/play) · Early Access target: Q2 2027

## Stack

| Layer | Tool |
|---|---|
| Site | Static HTML/CSS/JS, generated by small Node scripts — no framework |
| Hosting | Cloudflare Workers static assets; Workers Builds deploys every push to `main` |
| API | `src/worker.js`: `/api/subscribe`, `/api/unsubscribe`, `/api/report` (Resend) |
| Domain | echoesofthegarden.com (`www` and `.es` redirect to it), DNS on Cloudflare. The old Netlify site (`echoes-of-the-garden.netlify.app`) is switched off: its links return 404 |

Worker secrets (`npx wrangler secret put NAME`): `RESEND_API_KEY`, `RESEND_AUDIENCE_ID`, `REPORT_EMAIL`,
`UNSUBSCRIBE_SECRET` (any long random string; signs the one-click unsubscribe links — without it the
mails fall back to a `mailto:` unsubscribe).

## Project Structure

```
index.html                     # homepage (bestiary and dev log blocks are baked in by the scripts)
privacy/index.html, 404.html   # hand-written pages
bestiary/index.html            # generated: every species
bestiary/{slug}/index.html     # generated: one page per creature
devlog/…                       # generated from scripts/devlog-entries.mjs
es/, it/                       # generated translations of every page above
assets/creatures/              # sprites copied by `npm run bestiary`
assets/screenshots/            # copied from the game repo `marketing/steam/`
scripts/                       # build-bestiary, build-devlog, build-i18n, site-chrome (shared header + CTA)
src/worker.js                  # API, tests in src/worker.test.mjs
i18n/{es,it}.json              # translations, key = the English text
.well-known/security.txt       # RFC 9116 contact; renew Expires before 2027-11-10 (allowlisted in .assetsignore)
```

## Local Development

```bash
python3 -m http.server 8765    # then open http://127.0.0.1:8765/
npm test                       # worker tests
npx wrangler dev               # site + API locally (needs .dev.vars with the secrets)
```

Opened locally, the newsletter form runs in preview mode: it shows a success message without calling the API.

## Building

```bash
npm run bestiary   # after game creature or lore changes (reads the game checkout at ../echoes-of-the-garden)
npm run build      # dev log, then /es/ and /it/ — run after any text change, before pushing
```

The language build fails and names the text if a translation is missing: add it to `i18n/es.json` and
`i18n/it.json` (key = the English text). `node scripts/build-i18n.mjs --missing` writes the list to `i18n/missing.txt`.
Creature lore comes from the game's `i18n/content.csv`.

## Content Updates

| What to update | Where |
|---|---|
| Game description, sections | `index.html`, then `npm run build` |
| Newsletter welcome email | `src/worker.js` |
| Header and closing CTA of generated pages | `scripts/site-chrome.mjs` (hand copy in `privacy/index.html` and `404.html`) |
| OG image / social preview | `og-image.jpg` (1200×630px) |
| Screenshots | copy from the game repo `marketing/steam/` into `assets/screenshots/`, update `#screenshots` in `index.html` |
| Hero video | `assets/screenshots/garden_loop.mp4` + `garden_loop-poster.webp`, made from the game repo's `marketing/steam/garden_loop.gif` with `ffmpeg -i garden_loop.gif -an -movflags +faststart -pix_fmt yuv420p -c:v libx264 -crf 28 -vf scale=1280:720:flags=neighbor garden_loop.mp4` |
| Dev log entries | `scripts/devlog-entries.mjs`, then `npm run build` |
| Roadmap changes | `.rm-item` blocks in `index.html` by hand — source of truth is the game repo's `ROADMAP.md` (Phase 4 before Phase 3 per ADR-012) |
| Bestiary / creature pages | `npm run bestiary`, then `npm run build` |
